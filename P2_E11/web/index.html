Qué aporta E11

Un pronóstico real alimenta la convección de las caras expuestas. Python calcula conducción, calor de hidratación y activación de cada vertida.

La comparación mantiene iguales la malla, las vertidas, el material, el suelo y el moldaje. Solo cambia la temperatura del aire.

q″ = (Tcelda − Tamb(t)) / [Δn/(2k) + Rmoldaje + 1/h]

h constante; sin viento ni radiación explícitos. El núcleo puede diferir del punto más caliente.
