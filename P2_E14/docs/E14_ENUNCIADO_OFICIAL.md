# E14 — Semana 5 / jueves — Lab: Monte Carlo + HPC

Transcripción del enunciado facilitado por el usuario para esta auditoría.

**Fecha:** jueves 19 de noviembre, 10:30–12:30. **Puntaje:** 4 puntos.

## Objetivo

Demostrar un workflow paralelo reproducible de Monte Carlo en el cluster.

## Antes de la actividad

Tener sampler, ejecución parametrizada, extracción automática de métricas, agregación y script Slurm o equivalente.

## Durante la actividad

El ayudante puede pedir generar nuevas muestras, mostrar seeds, ejecutar un batch, inspeccionar un job, explicar inputs/outputs, agregar resultados, mostrar Pf(N) y explicar por qué las realizaciones son independientes.

No se evaluará complejidad innecesaria de MPI.
