## Revisión de las fórmulas y del código

En `src/mcoc_p2/verification_e05.py`, `sine_mode` forma el producto de senos en
los centros de celda. `eigenvalues` calcula para la referencia continua
alpha*sum((pi/L_a)^2), con alpha=k/(rho cp). `run_case` usa la referencia
T0+A*producto(senos)*exp(−alpha*lambda*t). Coincide con los casos 2D y 3D
del enunciado. El caso 1D es la misma solución con un solo seno.

Las caras tienen Dirichlet T0. Los centros no se sobrescriben con T0:
x_i=(i+1/2)*dx y dx=L/n. El solver nodal 1D heredado usa otra malla,
dx=L/(nx−1); sus pruebas permanecen separadas. No se mezclan ambos criterios.

Para una fuente uniforme en una caja adiabática homogénea, la referencia es
T(t)=T_ini+q0*t/(rho cp). La verificación compara todos los instantes guardados
y exige ΔE=q0*V*t. q0 tiene unidades W/m³; un flujo Neumann tiene W/m² y se
multiplica por el área. La conservación heterogénea pondera cada temperatura
con su capacidad térmica; no exige que la media aritmética sea constante.

`thermal_nd.CartesianSystem.power` suma cada intercambio interno con signos
opuestos. `boundary_heat_rates` usa flujo positivo saliente en ambas caras
de cada eje. Robin combina dx_normal/(2*k)+1/h; usa la temperatura superficial,
distinta de la del centro. Se acumulan las caras incidentes en bordes y esquinas.

`solve_nd` aplica Euler explícito con cota suficiente min(C_i/sum(G_i)),
incluidas las conductancias de frontera. Esta cota de monotonía no se presenta
como el límite espectral exacto de cualquier problema. El paso solicitado se
rechaza si la supera y el aceptado puede reducirse para llegar al tiempo final.
Un paso estable puede incumplir precisión: la CLI distingue PASS, FAIL numérico
y entrada rechazada mediante códigos 0, 1 y 2.

## Hallazgos y mejoras realizadas

1. **Ubicación y documentación confusas.** El código E05 está dentro de P2_E07;
   los documentos heredados indicaban entrar en una carpeta P2_E05 que no existe
   en esta copia. Se añadió [E05.md](../../E05.md), se señalaron los documentos
   históricos y se creó [VERIFICAR_E05.ps1](../../VERIFICAR_E05.ps1). El lanzador
   usa el entorno instalado, permite elegir una salida nueva y conserva el
   código de salida del verificador. Se ejecutó realmente para esta revisión.

2. **Cobertura de borde mejorable.** Ya existían pruebas de balances, signos,
   resistencias y algunos perfiles exactos. Se añadieron 30 pruebas en
   [test_e05_auditoria.py](../tests/test_e05_auditoria.py):
   12 perfiles transientes Neumann con flujo no nulo, 12 modos Robin con cambios
   de eje/cara/Biot y calentamiento/enfriamiento, 3 estudios espaciales Robin y
   3 ejecuciones CLI exactas con parámetros modificados y lectura de los campos
   guardados. Las nuevas pruebas forman parte de la verificación habitual.

3. **Trazabilidad actualizada.** Se guardaron las ejecuciones previa y final,
   parámetros, referencias independientes, tolerancias, figuras y resultados.
   Los conteos antiguos de 198 tests se conservan como históricos, no como el
   estado de la suite actual.

No se encontró una deficiencia del solver que exigiera cambiar su esquema para
E05. Se conservaron los archivos Python heredados y las tolerancias originales;
la ampliación agrega pruebas, acceso y documentación.

## Referencias independientes añadidas

Para Neumann se usa, sobre cualquier eje de una caja no cúbica:

```text
T(x,t)=T0+(q/k)*(L/2−x)+A*cos(pi*x/L)*exp(−alpha*(pi/L)^2*t)
q_out(x=0)=−q; q_out(x=L)=q; las otras caras son adiabáticas.
```

El flujo neto es cero. Un código que conserva energía pero distribuye mal las
temperaturas puede fallar esta comparación. Se prueban flujos de −73 y
+119 W/m², k=2,7 W/(m K), rho=2310 kg/m³ y cp=870 J/(kg K). El error máximo
observado fue **0,001965 °C**, frente al umbral previo de 0,003 °C.

Para Robin se resuelve por bisección la primera raíz de mu*tan(mu)=h*L/k:

```text
T(x,t)=Tamb+A*cos(mu*x/L)*exp(−alpha*(mu/L)^2*t)
x=0 adiabático, x=L Robin; se refleja x para probar la cara opuesta.
```

Se probaron Biot 0,25 y 3, amplitudes ±8 °C y las tres direcciones. El error
máximo fue **0,000379 °C**, frente a 0,01 °C. Para Biot 1,3, las mallas
de 10/20/40 celdas dieron órdenes cercanos a **1,953 y 2,004** en 1D/2D/3D,
con un paso común pequeño para limitar la contaminación temporal.

Estas soluciones se construyen desde la PDE y las condiciones físicas;
no se obtienen llamando al cálculo numérico de potencia o de flujo del solver.
Las tolerancias no se ajustaron para hacer aprobar resultados observados.

## Uso y límites

Desde la raíz del repositorio: `./VERIFICAR_E05.ps1`. Para seleccionar y
modificar casos, seguir los comandos de [E05.md](../../E05.md). Las salidas
existentes se protegen frente a sobrescritura. Los errores deliberados de
estabilidad/unidades/precisión se comprueban como controles negativos;
no son fallos ocultados de la suite.

La auditoría verifica cajas ideales, propiedades constantes y fronteras/fuentes
prescritas. No prueba una predicción térmica de la fundación real ni una
calibración. El alcance es E05; las siguientes entregas se revisarán con sus
propias instrucciones. La interfaz E07 existente conserva su alcance previo.

nuevo SHA pendientes de las acciones correspondientes del grupo y del usuario.
