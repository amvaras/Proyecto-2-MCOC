extracción y voxelización, integración térmica por etapas, hidratación,
interfaz HTML conectada a Python y evidencias. Los accesos desde la raíz son
E08.md, INICIAR_E08.bat y VERIFICAR_E08.ps1.

La verificación final aprobó **327 pruebas**, sin fallos, errores ni omisiones,
60 variantes térmicas y dos simulaciones E08. La referencia tiene 73 fotogramas.
La interfaz se comprobó con cambios de resolución, calendario, colocación,
visibilidad y reproducción temporal. Código y datos numéricos se conservan
exactamente como fueron verificados.
